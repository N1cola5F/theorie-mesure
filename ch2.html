2.1 Image réciproque（核心工具） ​

Prop 2.1.1 — Propriétés algébriques 逆像的代数性质

设 X:E→F。则

  • X−1(∅)=∅，X−1(F)=E；
  • X−1(Bc)=(X−1(B))c（补的逆像 = 逆像的补）；
  • X−1(⋃iBi)=⋃iX−1(Bi)，X−1(⋂iBi)=⋂iX−1(Bi)；
  • Bi 两两不交 ⇒X−1(Bi) 两两不交。

口诀：逆像与一切集合运算交换。

Prop 2.1.2 — X−1(S) 是 E 上的 tribu

X−1(S)={X−1(B):B∈S} 是 E 上的 σ-代数。

Prop 2.1.3 — 到达域上的 tribu

给定 (E,T) 与 X:E→F，则 S={B⊂F:X−1(B)∈T} 是 F 上的 σ-代数。

Prop 2.1.4 — 交换性（关键）

X−1(σ(G))=σ(X−1(G)).

故只需在 S 的生成系 G 上验证 X−1(G)∈T 即可保证可测。

交互演示：切换运算 ∪/∩/∖/c，验证 X−1(运算)=运算(X−1) 恒成立（逆像与一切集合运算交换）。

2.2 Fonctions mesurables ​

Déf 2.2.1 — Fonction mesurable / Variable aléatoire

f:(E,T)→(F,S) 可测 ⟺∀B∈S, f−1(B)∈T。

  • 概率空间上的可测函数称 variable aléatoire（随机变量）；
  • T,S 均为博雷尔时称 fonction borélienne。

Déf 2.2.2 — Fonction simple / étagée 简单（阶梯）函数

存在两两不交的 (Ak)1≤k≤n∈Tn 与 (xk)∈Rn，使

X=∑k=1nxk1Ak.

Déf 2.2.3–4 — R― 与运算

R―=R∪{−∞,+∞}，B(R―)={A⊂R―:A∩R∈B(R)}。

  • x+(±∞)=±∞ (x∈R)；
  • 约定 0⋅(±∞)=0（保持积分一致）；
  • ∞−∞ 未定义。

Prop 2.2.1 — Composition 复合

f,g 可测 ⇒g∘f 可测。

Prop 2.2.2 — 由生成系判可测（关键判定）

若 σ(G)=S，则

f mesurable⟺∀G∈G, f−1(G)∈T.

典型取 G={(−∞,a]:a∈R} 或开集族。

Prop 2.2.3 — Stabilité par sup / inf / limsup / liminf

(fn) 可测族 ⇒supnfn, infnfn, lim supnfn, lim infnfn 均可测。

Prop 2.2.4–7 — Exemples fondamentaux 基本例

  • 1A（A∈T）可测；
  • f 连续（博雷尔）⇒ 可测；
  • X+Y,XY,λX,|X| 可测（算术稳定性）；
  • 向量值 X=(X1,…,Xn):E→Rn 可测 ⟺ 每个分量 Xi 可测。

Prop 2.2.8–9 — Lemme d'approximation 逼近引理

X:E→[0,+∞] 可测 ⟺ 存在非负阶梯函数列 (Xn) 逐点单增趋于 X。构造：

Xn=∑k=0n2n−1k2n1{k/2n≤X<(k+1)/2n}+n1{X≥n}.

随机变量 X:Ω→R，事件 {X≤a}=X−1((−∞,a])∈T，故可谈「X 取这种值的概率」。

2.3 Intégration de Lebesgue（四步构造） ​

构造路线： (1) 阶梯正函数 → (2) 可测正函数（sup 逼近）→ (3) 实可测（X+−X−）→ (4) 在事件 A 上限制（∫A=∫X1A）。

Déf 2.3.1 — ① Fonction étagée positive

f=∑k=1nxk1Ak (xk≥0)：

∫fdμ=∑k=1nxkμ(Ak)(不依赖于划分).

Déf 2.3.2 — ② Fonction mesurable positive

X:Ω→[0,+∞] 可测：

∫Xdμ=sup{∫Sdμ:0≤S≤X, S étagée}∈[0,+∞].

若 ∫Xdμ<+∞ 称 X 为 μ-intégrable。

Déf 2.3.3 — ③ Fonction mesurable réelle

X+=sup(X,0), X−=sup(−X,0) 均可测正。若 ∫X+dμ,∫X−dμ<+∞：

∫Xdμ=∫X+dμ−∫X−dμ.

X intégrable ⟺|X| intégrable（因 |X|=X++X−）。

Déf 2.3.4 — ④ Intégrale sur A∈T

∫AXdμ=∫X⋅1Adμ.

Déf 2.3.5 — Presque partout (p.p. / p.s.)

性质 P 在 Ω 上 μ-p.p. ⟺∃A∈T, μ(A)=0, ∀ω∈Ac, P(ω) 真。概率情形称 presque sûr。

Prop 2.3.3–5 — Propriétés 性质（线性、单调、可积性）

X,Y 正或可积：

  • 线性：∫(X+Y)=∫X+∫Y，∫λX=λ∫X；
  • 单调：X≤Y⇒∫X≤∫Y；X=Y p.p. ⇒ 积分相等；
  • X 可积 ⟺|X| 可积；X 可积 ⇒X p.p. 有限；
  • |X|≤Y 且 Y 可积 ⇒X 可积；
  • 不交 A,B：∫A∪B=∫A+∫B。

Exercice 2.3.2 — Riemann ↔ Lebesgue

f:[a,b]→R Riemann 可积 ⇒ Lebesgue 可积，且 ∫abf(t)dt=∫[a,b]fdλ。反之不一定：1Q 不 Riemann 可积，但 Lebesgue 可积且 ∫[a,b]1Qdλ=0。

Exercice 2.3.3 — 计数测度

μ(A)=Card(A∩N)：∫fdμ=∑nf(n) —— 测度论积分 = 级数。

2.3′ Trois théorèmes de convergence（核心三定理） ​

Th 2.3.1 — Convergence monotone (TCM, Beppo-Levi)

(Xn) 可测正、逐点单增趋于 X ⇒X 可测且

∫Xdμ=limn→∞∫Xndμ(允许=+∞).

级数形式：Yn≥0 可测 ⇒∫∑nYndμ=∑n∫Yndμ。

Th 2.3.2 — Lemme de Fatou

(Xn) 可测正：

∫lim infnXndμ≤lim infn∫Xndμ.

不等号可严格：Xn=12n1[−n,n]，∫Xn=1→∫0=0。

Th 2.3.3 — Convergence dominée (TCD, Lebesgue)

(Xn) 可测，假设：Xn→X p.p.，且 ∃Y≥0 使 |Xn|≤Y 与 ∫Ydμ<+∞（支配假设）。则 X 可积且

∫Xdμ=limn∫Xndμ,limn∫|Xn−X|dμ=0.

Note — 三定理对比

  • TCM：单增 + 正 → 等式；
  • Fatou：仅正 → 不等式；
  • TCD：可控（dominée）→ 等式（最常用）。

反例（支配不可省）：fn=12n1[−n,n] 一致趋 0，但 ∫fn=1↛0。
