第一章 — Éléments de théorie de la mesure

Cadre：$(\Omega,\mathcal{T})$ 可测空间，$\mu$ 测度。本章建立测度论语言：可数集 / Tribu / Mesure / Borel-Cantelli。

1.1 Rappels théorie des ensembles

Déf 1.1.1Ensemble dénombrable 存在 $\varphi:E\to\mathbb{N}$ 单射。
  • $\varphi$ 双射 → infini dénombrable；否则 fini。
  • $\mathbb{Z},\mathbb{Q},\mathbb{N}\times\mathbb{N}$ 可数；$\mathcal{P}(\mathbb{N}),\mathbb{R}$ 不可数。
Déf 1.1.2Induction structurelle $A\subset E$ 由：(i) 生成部分 $B\subset A$；(ii) 构造规则 $f:A^I\to E$ 给出。$A$ 是满足这两条的最小子集。
Déf 1.1.3Définition récursive d'une fonction $g:E\to F$：在 $B$ 上已知；存在 $U:F^I\to F$ 使 $g(f((e_i)))=U((g(e_i)))$。
Exemples
  • $\mathbb{N}$：$0\in\mathbb{N}$；$n\in\mathbb{N}\Rightarrow n+1\in\mathbb{N}$。
  • $K[X]$：$\lambda,X$ 是多项式；$P+Q,P\cdot Q$ 仍是。
  • Liste：$[\,]$ 是列表；$a::s$ 仍是 → 递归 $\mathrm{somme}$。

1.2 Limite supérieure / inférieure d'une suite d'ensembles

Déf 1.1.4$\limsup A_n$（无限多次） $$\limsup_{n} A_n=\bigcap_{n\in\mathbb{N}}\bigcup_{m\ge n}A_m$$ "$\omega$ 属于 无穷多个 $A_n$"。
Déf 1.1.4$\liminf A_n$（最终一直在） $$\liminf_{n} A_n=\bigcup_{n\in\mathbb{N}}\bigcap_{m\ge n}A_m$$ "$\omega$ 从某 $n$ 起一直在 $A_m$ 中"。
Prop 1.1.1关系 $\liminf A_n\subset \limsup A_n$；若相等则 $(A_n)$ 收敛。
Note 概率解读 抛硬币 $A_i=$"第 $i$ 次正面"：
  • $\limsup A_n$ = "出现无限多次正面"
  • $\liminf A_n$ = "从某次起一直正面"
Exercice 1.1.1 De Morgan：$\overline{\limsup A_n}=\liminf \overline{A_n}$，$\overline{\liminf A_n}=\limsup \overline{A_n}$。
Exercice 1.1.2 "硬币连续两次正面无穷多次"：$A_i=\{\omega_i=F,\omega_{i+1}=F\}$，事件 $=\limsup A_n$。

1.3 Tribus（$\sigma$-algèbre）

Déf 1.2.1Tribu $\mathcal{T}\subset\mathcal{P}(\Omega)$ 满足：
  • $\emptyset,\Omega\in\mathcal{T}$
  • $A\in\mathcal{T}\Rightarrow A^c\in\mathcal{T}$（complémentation）
  • $(A_n)\in\mathcal{T}^\mathbb{N}\Rightarrow \bigcup_n A_n\in\mathcal{T}$（réunion dénombrable）
Prop 1.2.2-4Stabilités dérivées
  • Différence propre：$A\subset B\Rightarrow B\setminus A\in\mathcal{T}$
  • Intersection dénombrable：$\bigcap_n A_n\in\mathcal{T}$
  • $\limsup A_n,\liminf A_n\in\mathcal{T}$
Déf 1.2.2Tribu engendrée $\mathcal{T}(\mathcal{G})$ 包含 $\mathcal{G}$ 的最小 tribu。
Prop 1.2.1：$\mathcal{T}(\mathcal{G})=\bigcap\{\mathcal{T}\text{ tribu}, \mathcal{G}\subset\mathcal{T}\}$
Déf 1.2.3Tribu borélienne $\mathcal{B}(E)$ $E$ evn，$\mathcal{O}$ = ouverts。$\mathcal{B}(E)=\mathcal{T}(\mathcal{O})$。元素称 borélien。
Déf 1.2.4Espace mesurable / probabilisable $(\Omega,\mathcal{T})$ → événements = 元素 $\in\mathcal{T}$。 若 $\Omega$ 可数，常取 $\mathcal{T}=\mathcal{P}(\Omega)$。
Exemple 1.2.1-2
  • 最小 tribu：$\{\emptyset,\Omega\}$
  • $\mathcal{P}(\Omega)$ 总是 tribu
  • $\{A\subset\mathbb{R}: A\text{ ou }A^c\text{ dénombrable}\}$ 是 tribu
Exercice 1.2.3 $\mathbb{R}$ 上 $\mathcal{B}(\mathbb{R})$：单点 $\{a\}=\bigcap_n(a-2^{-n},a+2^{-n})$ → 是 borélien；故 $\mathbb{Q},\mathbb{R}\setminus\mathbb{Q}$ 都是。
Note 系统 Dynkin（Ex 1.2.4-5） $\mathcal{D}$ Dynkin = (i) $\Omega\in\mathcal{D}$ (ii) $A\subset B\Rightarrow B\setminus A\in\mathcal{D}$ (iii) 不交 $\sigma$-réunion 稳定。
Théorème des classes monotones：若 $\mathcal{G}$ 对有限交稳定，则 $\mathcal{D}(\mathcal{G})=\mathcal{T}(\mathcal{G})$ —— 证唯一性的关键工具。

1.4 Mesure

Déf 1.3.1Mesure $\mu$ $\mu:\mathcal{T}\to[0,+\infty]$ 满足：
  • $\mu(\emptyset)=0$
  • $\sigma$-additivité：$(A_n)$ 两两不交 $\Rightarrow \mu(\bigcup A_n)=\sum_n \mu(A_n)$
Déf 1.3.1Variantes
  • Finie：$\mu(\Omega)<+\infty$
  • $\sigma$-finie：$\Omega=\bigcup A_n$，$\mu(A_n)<+\infty$
  • Probabilité：$\mu(\Omega)=1$（$(\Omega,\mathcal{T},\mathbb{P})$ probabilisé）
  • Négligeable：$\mu(A)=0$
Th 1.3.1 — LebesgueMesure de Lebesgue sur $\mathbb{R}^n$ 在 $(\mathbb{R}^n,\mathcal{B}(\mathbb{R}^n))$ 上存在唯一测度 $\lambda$ 满足： $$\lambda([a_1,b_1]\times\cdots\times[a_n,b_n])=\prod_{i=1}^n(b_i-a_i)$$ （存在性 ADMIS；唯一性来自 classes monotones）
Prop 1.3.1Propriétés élémentaires
  • Additivité finie：$A,B$ 不交 $\Rightarrow \mu(A\cup B)=\mu(A)+\mu(B)$
  • Monotonie：$A\subset B\Rightarrow \mu(A)\le \mu(B)$
  • Inclusion-exclusion：$\mu(A\cup B)=\mu(A)+\mu(B)-\mu(A\cap B)$
Prop 1.3.2 — ContinuitéCroissante / décroissante
  • $(A_n)$ croissante：$\mu(\bigcup A_n)=\lim \mu(A_n)$ （无附加假设）
  • $(B_n)$ décroissante，$\exists m, \mu(B_m)<+\infty$：$\mu(\bigcap B_n)=\lim \mu(B_n)$
Prop 1.3.3 — BooleSous-additivité dénombrable $\displaystyle\mu\!\left(\bigcup_n A_n\right)\le\sum_n \mu(A_n)$（不需要不交！）
Prop 1.3.4Caractérisation alternative $\mu$ 是测度 $\Leftrightarrow$ $\mu(\emptyset)=0$ + 有限可加 + 递增连续。
Prop 1.3.5 — Borel-Cantelli关键引理（第一部分） 若 $\sum_n \mu(A_n)<+\infty$，则 $$\mu\!\left(\limsup_n A_n\right)=0.$$ 证：Boole 不等式 + 取尾巴 $\to 0$。
Exemples
  • 1.3.1：$\mu(A)=\mathrm{Card}(A\cap\mathbb{N})$ 是 $\sigma$-finie 概率测度
  • 1.3.3：$(u_n)$ 收敛正项级数 → $\mu(A)=\sum_{k\in A}u_k$ 是测度
  • 1.3.4：$\mathbb{R}^2$ 中 $A=\{0\le y\le f(x)\}$，$\lambda(A)=\int f\,dx$ → 测度↔积分桥梁
Attention 递减连续必须有 $\mu(B_m)<+\infty$！反例：$B_n=[n,+\infty)$，$\lambda(B_n)=+\infty$ 不收敛到 $\lambda(\emptyset)=0$。

第二章 — Fonctions mesurables et intégration

Cadre：$(E,\mathcal{T})$、$(F,\mathcal{S})$ espaces mesurables，$f:E\to F$。建立可测映射与Lebesgue 积分，并推广到任意测度空间。

2.1 Image réciproque（核心工具）

Prop 2.1.1Propriétés algébriques
  • $X^{-1}(\emptyset)=\emptyset$，$X^{-1}(F)=E$
  • $X^{-1}(B^c)=X^{-1}(B)^c$（补的逆像 = 逆像的补）
  • $X^{-1}(\bigcup B_i)=\bigcup X^{-1}(B_i)$；$X^{-1}(\bigcap B_i)=\bigcap X^{-1}(B_i)$
  • $B_i$ 不交 $\Rightarrow X^{-1}(B_i)$ 不交
口诀：逆像与所有集合运算交换。
Prop 2.1.2$X^{-1}(\mathcal{S})$ 是 $E$ 上的 tribu $X^{-1}(\mathcal{S})=\{X^{-1}(B):B\in\mathcal{S}\}$ 是 tribu。
Prop 2.1.3到达域上的 tribu 给 $(E,\mathcal{T})$ 与 $X:E\to F$，$\mathcal{S}=\{B\subset F: X^{-1}(B)\in\mathcal{T}\}$ 是 $F$ 上的 tribu。
Prop 2.1.4 — 关键交换性 $$X^{-1}(\mathcal{T}(\mathcal{G}))=\mathcal{T}(X^{-1}(\mathcal{G})).$$ 使得"在 $\mathcal{S}$ 的生成系上验证 $X^{-1}(G)\in\mathcal{T}$"就足以保证可测。

2.2 Fonctions mesurables

Déf 2.2.1Fonction mesurable / VA $f:(E,\mathcal{T})\to(F,\mathcal{S})$ 可测 $\Leftrightarrow \forall \Sigma\in\mathcal{S},\,f^{-1}(\Sigma)\in\mathcal{T}$.
  • 概率空间 → variable aléatoire
  • $\mathcal{T},\mathcal{S}$ boréliennes → fonction borélienne
Déf 2.2.2Fonction simple / étagée 存在不交 $(A_k)\in\mathcal{T}^n$ 与 $(x_k)\in\mathbb{R}^n$： $$X=\sum_{k=1}^n x_k\,\mathbf{1}_{A_k}.$$
Déf 2.2.3-4$\overline{\mathbb{R}}$ et opérations $\overline{\mathbb{R}}=\mathbb{R}\cup\{\pm\infty\}$，$\mathcal{B}(\overline{\mathbb{R}})=\{A\subset\overline{\mathbb{R}}: A\cap\mathbb{R}\in\mathcal{B}(\mathbb{R})\}$。
  • $x+(\pm\infty)=\pm\infty$（$x\in\mathbb{R}$）
  • 约定 $0\cdot(\pm\infty)=0$（保持后续积分运算一致）
  • $\infty-\infty$ 未定义
Prop 2.2.1Composition $f,g$ 可测 $\Rightarrow g\circ f$ 可测。
Prop 2.2.2 — 关键判定由生成系判可测 若 $\mathcal{T}(\mathcal{G})=\mathcal{S}$： $$f \text{ mesurable}\Leftrightarrow \forall G\in\mathcal{G},\,f^{-1}(G)\in\mathcal{T}.$$ 典型 $\mathcal{G}=\{(-\infty,a]:a\in\mathbb{R}\}$ 或开集族。
Prop 2.2.3Stabilité par sup, inf, limsup, liminf 可数 $(f_n)$ 可测族 $\to \sup f_n,\inf f_n,\limsup f_n,\liminf f_n$ 可测。
Prop 2.2.4-6Exemples fondamentaux
  • $\mathbf{1}_A$（$A\in\mathcal{T}$）可测
  • $f$ continue（boréliennes）→ mesurable
  • $X+Y,\,XY,\,\lambda X,\,|X|$ 可测（算术稳定性）
Prop 2.2.7Vectorielles $X=(X_1,\dots,X_n):E\to\mathbb{R}^n$ 可测 $\Leftrightarrow$ 每个 $X_i$ 可测。
Prop 2.2.8-9 — Lemme d'approximation阶梯函数逼近 $X:E\to[0,+\infty]$ 可测 $\Leftrightarrow$ 存在 $(X_n)$ étagées positives，逐点单增趋于 $X$。
构造：$X_n=\sum_{k=0}^{n2^n-1}\frac{k}{2^n}\mathbf{1}_{\{k/2^n\le X<(k+1)/2^n\}}+n\mathbf{1}_{\{X\ge n\}}$.
Exercice 2.2.1 若 $(f_n)\to f$ 逐点（且 $f_n$ 可测），则 $f$ 可测（用 $f=\liminf f_n=\limsup f_n$）。
Note 概率视角 随机变量 $X:\Omega\to\mathbb{R}$，事件 $\{X\le a\}=X^{-1}(]-\infty,a])\in\mathcal{T}$，所以可以谈"$X$ 取这种值的概率"。

2.3 Intégration de Lebesgue（四步构造）

构造路线：(1) 阶梯正函数 → (2) 可测正函数（sup 逼近）→ (3) 实可测（$X^+-X^-$）→ (4) 在事件 $A$ 上限制（$\int_A=\int X\mathbf{1}_A$）。

Déf 2.3.1① Fonction étagée positive $f=\sum_{k=1}^n x_k\mathbf{1}_{A_k}$（$x_k\ge 0$）： $$\int f\,d\mu=\sum_{k=1}^n x_k\,\mu(A_k).$$ 定义不依赖于划分（验证：取细分公共划分）。
Déf 2.3.2② Fonction mesurable positive $X:\Omega\to[0,+\infty]$ 可测： $$\int X\,d\mu=\sup\!\left\{\int S\,d\mu : 0\le S\le X,\ S\text{ étagée}\right\}\!\in[0,+\infty].$$ 若 $\int X\,d\mu<+\infty$，称 $X$ $\mu$-intégrable。
Déf 2.3.3③ Fonction mesurable réelle $X^+=\sup(X,0),\,X^-=\sup(-X,0)$，两者均可测正。若 $\int X^+\,d\mu,\int X^-\,d\mu<+\infty$： $$\int X\,d\mu=\int X^+\,d\mu-\int X^-\,d\mu.$$ $X$ intégrable $\Leftrightarrow$ $|X|$ intégrable（因 $|X|=X^++X^-$）。
Déf 2.3.4④ Intégrale sur $A\in\mathcal{T}$ $\int_A X\,d\mu = \int X\cdot\mathbf{1}_A\,d\mu.$
Déf 2.3.5Presque partout（p.p. / p.s.） 性质 $P$ 在 $\Omega$ 上 $\mu$-p.p. $\Leftrightarrow \exists A\in\mathcal{T},\ \mu(A)=0,\ \forall\omega\in A^c, P(\omega)$ 真。 概率情形称 presque sûr。
Prop 2.3.3-5Propriétés (linéarité, monotonie, intégrabilité) $X,Y$ 正或可积：
  • Linéarité：$\int(X+Y)=\int X+\int Y$，$\int \lambda X=\lambda\int X$
  • Monotonie：$X\le Y\Rightarrow \int X\le \int Y$；$X=Y$ p.p.$\Rightarrow$ 积分相等
  • $X$ 可积 $\Leftrightarrow |X|$ 可积；$X$ 可积 $\Rightarrow X$ p.p. fini
  • $|X|\le Y$，$Y$ 可积 $\Rightarrow X$ 可积
  • 不交 $A,B$：$\int_{A\cup B}=\int_A+\int_B$
Exercice 2.3.2 — Riemann ↔ Lebesgue $f:[a,b]\to\mathbb{R}$ Riemann 可积 $\Rightarrow$ Lebesgue 可积，且 $\int_a^b f(t)dt=\int_{[a,b]}f\,d\lambda$。
反之不一定：$\mathbf{1}_\mathbb{Q}$ 不 Riemann 可积，但 Lebesgue 可积，$\int_{[a,b]}\mathbf{1}_\mathbb{Q}d\lambda=0$。
Exercice 2.3.3 — 计数测度 $\mu(A)=\mathrm{Card}(A\cap\mathbb{N})$（$\mathbb{R}$ 上 $\mathcal{P}(\mathbb{R})$）： $\int f\,d\mu=\sum_n f(n)$ → 测度论积分 = 级数。
Note — 与 Riemann 的关系 Lebesgue 积分严格推广 Riemann：所有 Riemann 可积函数都 Lebesgue 可积且值相等；额外能积更"病态"的函数（如 $\mathbf{1}_\mathbb{Q}$）。
Exercice 2.3.4 — 范围估计 $m\le X\le M$ 在 $A$ 上，$\mu(A)<\infty$：$m\mu(A)\le \int_A X\,d\mu\le M\mu(A)$.

2.3' Trois théorèmes de convergence（核心三定理）

Th 2.3.1 — Convergence monotone (TCM)Beppo-Levi $(X_n)$ 可测正，逐点单增趋于 $X$ → $X$ 可测且 $$\int X\,d\mu=\lim_{n\to\infty}\int X_n\,d\mu\quad \text{(允许 }=+\infty\text{)}.$$ 级数形式：$Y_n\ge 0$ 可测 $\Rightarrow\displaystyle\int\sum_n Y_n\,d\mu=\sum_n \int Y_n\,d\mu$.
Th 2.3.2 — Lemme de Fatou不等式 $(X_n)$ 可测正： $$\int \liminf_n X_n\,d\mu\le \liminf_n \int X_n\,d\mu.$$ 不等号严格可发生（Ex 2.3.8：$X_n=\frac{1}{2n}\mathbf{1}_{[-n,n]}$，$\int X_n=1\to\int 0=0$）。
Th 2.3.3 — Convergence dominée (TCD)Lebesgue $(X_n)$ 可测，假设：
  • $X_n\to X$ p.p.
  • $\exists Y\ge 0$ avec $|X_n|\le Y$（hypothèse de domination）且 $\int Y\,d\mu<+\infty$
则 $X$ 可积且 $$\int X\,d\mu=\lim_n\int X_n\,d\mu,\qquad \lim_n\int|X_n-X|\,d\mu=0.$$
Note 三定理对比
  • TCM：单增 + 正 → 等式
  • Fatou：仅正 → 不等式
  • TCD：可控（dominée）→ 等式（最常用）
Attention — TCD 的反例 若没有可积 $Y$ 控制：$f_n=\frac{1}{2n}\mathbf{1}_{[-n,n]}$ 一致趋 0，但 $\int f_n=1\not\to 0$。
→支配假设不可省。
Exercice 2.3.6 — TCM 递减版 若 $X_1$ 可积且 $X_n\downarrow 0$ p.p.，则 $\int X_n\to 0$（用 $Y_n=X_1-X_n\uparrow X_1$ 套 TCM）。
反例（无 $X_1$ 可积）：$X_n=\mathbf{1}_{[n,+\infty[}$ 递减 $\to 0$ 但 $\int X_n=+\infty$。
Exercice 2.3.10 — TCD 应用 $f_n(x)=\sin^n(1/x)\mathbf{1}_{0<|x|<1}$：$|f_n|\le \mathbf{1}_{[-1,1]}$ 可积，$f_n\to 0$ p.p. → $\int f_n\to 0$。

第三章 — Variables aléatoires réelles

Cadre：$(\Omega,\mathcal{T},\mathbb{P})$ probabilisé，$X:\Omega\to\mathbb{R}$ VA。研究 loi、fonction de répartition、densité、espérance、indépendance。

3.1 Compléments — Fubini-Tonelli & Changement de variable

Déf 3.1.1Tribu et mesure produit $(E,\mathcal{T},\mu),(F,\mathcal{S},\nu)$：
  • $\mathcal{T}\otimes\mathcal{S}=\mathcal{T}((A\times B)_{A\in\mathcal{T},B\in\mathcal{S}})$
  • $\mu\otimes\nu$：唯一测度，$\mu\otimes\nu(A\times B)=\mu(A)\nu(B)$（约定 $0\cdot\infty=0$）
例：$\mathbb{R}\times\mathbb{R}\to \lambda^{\otimes 2}=$ Lebesgue 在 $\mathbb{R}^2$。
Th 3.1.1 — Tonelli$f\ge 0$ mesurable $\mu,\nu$ $\sigma$-finies。对正可测 $f:E\times F\to[0,+\infty]$： $$\int_{E\times F}\!\!f\,d(\mu\otimes\nu)=\int_E\!\!\left(\!\int_F f(x,y)d\nu\!\right)\!d\mu=\int_F\!\!\left(\!\int_E f(x,y)d\mu\!\right)\!d\nu.$$ 正性自动保证三式合理（可以 $=+\infty$）。
Th 3.1.2 — Fubini$f$ intégrable 若 $\int_{E\times F}|f|\,d(\mu\otimes\nu)<+\infty$：
  • $\mu$-p.p. $x$，$y\mapsto f(x,y)$ $\nu$-可积；$\nu$-p.p. $y$ 类似
  • 积分换序成立（同 Tonelli 公式）
实用：先用 Tonelli 检查 $\int|f|<\infty$，再用 Fubini 换序。
Note 序-积分互换 $E=\mathbb{N}$（计数），$F=\mathbb{R}$（Lebesgue）：Fubini = 级数-积分换序定理。
Th 3.1.3 — Changement de variable在 $\mathbb{R}^n$ $\Phi:\Omega\to U$ 满足：
  1. 双射 $\Omega\to U$
  2. $\Phi\in C^1$
  3. $\det\mathrm{Jac}_\Phi(x)\ne 0$（$\forall x$ 或 p.p.）
则 $$\int_U f(y)\,dy=\int_\Omega (f\circ\Phi)(x)\,|\det\mathrm{Jac}_\Phi(x)|\,dx.$$ （$f\ge 0$ 时无须 intégrabilité 假设。）
Exemples
  • 3.1.1：$\int_{0\le x_1\le \cdots\le x_n\le a}\!dx_1\cdots dx_n=a^n/n!$
  • 3.1.2：极坐标 → $\int_{\mathbb{R}}e^{-t^2}dt=\sqrt\pi$
  • 3.1.3：$u=xy,v=y$ 求 $\int_{[0,1]^2}\varphi(xy)dxdy=\int_0^1\varphi(u)(-\ln u)du$ → $f(u)=-\ln u\cdot\mathbf{1}_{]0,1[}$
Attention Tonelli 与 Fubini 都要求 $\sigma$-finie！例如 $\mu=$ comptage 在 $\mathbb{R}$（不可数）就不 $\sigma$-finie，结论可能失败。

3.2 Variables aléatoires — Loi, $F_X$, espérance, transfert

Déf 3.2.1Variable aléatoire (VA) $X:(\Omega,\mathcal{T},\mathbb{P})\to(E,\mathcal{S})$ mesurable. $E=\mathbb{R}$ → VA réelle.
Déf 3.2.2Loi $\mathbb{P}_X$（mesure image） $\forall A\in\mathcal{S},\ \mathbb{P}_X(A)=\mathbb{P}(X^{-1}(A))=\mathbb{P}(X\in A).$
$\mathbb{P}_X$ 是 $(E,\mathcal{S})$ 上的概率测度。
Déf 3.2.3Fonction de répartition $F_X$ $\forall a\in\mathbb{R},\ F_X(a)=\mathbb{P}(X\le a).$
Prop 3.2.2Propriétés de $F_X$
  • croissante sur $\mathbb{R}$
  • $\lim_{-\infty}F_X=0,\ \lim_{+\infty}F_X=1$
  • continue à droite（用 décroissance + finitude）
Prop 3.2.1$F_X$ caractérise la loi $\mathbb{P}_X=\mathbb{P}_Y\Leftrightarrow \forall a, F_X(a)=F_Y(a)$.
证：$(]-\infty,a])$ 是 stable par $\cap$ → classes monotones。
Prop 3.2.3-4Caractérisation par $\varphi$ continue 等价于：
  • $\forall \varphi\in C_c(\mathbb{R})$（continue support compact），$\mathbb{E}[\varphi(X)]=\mathbb{E}[\varphi(Y)]$
  • $\forall \varphi\in C_b(\mathbb{R})$（continue bornée）相同
Déf 3.2.4VA discrète 存在 $S$ 可数，$\mathbb{P}(X\in S)=1$。例：VA finies、$\mathbb{N}$-valuées。
Déf 3.2.5VA à densité (absolument continue) $\exists f:\mathbb{R}\to\mathbb{R}$ mesurable, $f\ge 0$, $\int_\mathbb{R} f=1$，且 $$\forall A\in\mathcal{B}(\mathbb{R}),\ \mathbb{P}(X\in A)=\int_A f(t)\,dt.$$ $f$ 称 densité de probabilité。
Déf 3.2.6-8Espérance, moment, variance
  • $\mathbb{E}(X)=\int_\Omega X\,d\mathbb{P}$（si $\mathbb{P}$-intégrable）
  • Moment ordre $k$：$\mathbb{E}(|X|^k)<+\infty\Rightarrow \mathbb{E}(X^k)$
  • $\mathrm{Var}(X)=\mathbb{E}((X-\mathbb{E}X)^2)=\mathbb{E}(X^2)-\mathbb{E}(X)^2$（König-Huygens）
Th 3.2.1 — 关键 / Formule de transfertThéorème de transport $X:\Omega\to\mathbb{R}$ VA，$f:\mathbb{R}\to\mathbb{R}$ mesurable： $$\boxed{\ \mathbb{E}(f(X))=\int_\mathbb{R} f(x)\,d\mathbb{P}_X(x)\ }$$
  • $X$ 离散，$\mathbb{P}(X=x_k)=p_k$：$\mathbb{E}(f(X))=\sum_k p_k f(x_k)$
  • $X$ 有密度 $f_X$：$\mathbb{E}(f(X))=\int_\mathbb{R} f(x)\,f_X(x)\,dx$
证：$\mathbf{1}_A$ → étagée（线性）→ 正可测（TCM）→ 实可测（$\pm$ 分解）。
Exercice 3.2.1 $X$ 有密度 $\mathbf{1}_{[0,+\infty[}(x)e^{-x}$（$\mathcal{E}(1)$）：用分部积分得 $\mathbb{E}(X^k)=k!$。

3.3 Lois usuelles

3.3.1 — Lois discrètes

LoiUniforme $\mathcal{U}(E)$（$|E|=n$） $\mathbb{P}(X=e)=\dfrac{1}{n}$.
典型：骰子、抽签。
LoiBinomiale $\mathcal{B}(n,p)$ $\mathbb{P}(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$，$k\in\{0,\dots,n\}$.
$\mathbb{E}(X)=np,\ \mathrm{Var}(X)=np(1-p)$. n 次独立 Bernoulli($p$) 的成功次数。
LoiHypergéométrique $\mathcal{H}(n,N,p)$ $\mathbb{P}(X=k)=\dfrac{\binom{N_1}{k}\binom{N_2}{n-k}}{\binom{N}{n}}$，$N_1=Np,N_2=N(1-p)$.
不放回抽样模型（与 $\mathcal{B}$ 对比：放回）。
LoiGéométrique $\mathcal{G}(p)$ $\mathbb{P}(X=k)=(1-p)^{k-1}p$，$k\ge 1$.
$\mathbb{E}(X)=1/p,\ \mathrm{Var}(X)=(1-p)/p^2$. 首次成功时刻；无记忆性（离散）。
LoiPoisson $\mathcal{P}(\lambda)$ $\mathbb{P}(X=k)=\dfrac{e^{-\lambda}\lambda^k}{k!}$，$k\in\mathbb{N}$.
$\mathbb{E}(X)=\mathrm{Var}(X)=\lambda$. 稀有事件计数（$\mathcal{B}(n,\lambda/n)\to\mathcal{P}(\lambda)$）。

3.3.2 — Lois à densité

LoiUniforme $\mathcal{U}([a,b])$ $f(x)=\dfrac{1}{b-a}\mathbf{1}_{[a,b]}(x)$.
$\mathbb{E}(X)=\dfrac{a+b}{2},\ \mathrm{Var}(X)=\dfrac{(b-a)^2}{12}$.
LoiExponentielle $\mathcal{E}(\lambda)$，$\lambda>0$ $f(x)=\lambda e^{-\lambda x}\mathbf{1}_{]0,+\infty[}(x)$.
$\mathbb{E}(X^k)=\dfrac{k!}{\lambda^k}$；$\mathbb{E}(X)=1/\lambda,\ \mathrm{Var}(X)=1/\lambda^2$.
无记忆性（连续）：$\mathbb{P}(X>s+t\mid X>s)=\mathbb{P}(X>t)$.
LoiNormale réduite $\mathcal{N}(0,1)$ $f(x)=\dfrac{1}{\sqrt{2\pi}}e^{-x^2/2}$.
$\mathbb{E}(X)=0,\ \mathrm{Var}(X)=1$. 矩：$\mathbb{E}(X^{2k+1})=0,\ \mathbb{E}(X^{2k})=\dfrac{(2k)!}{k!\,2^k}$.
LoiNormale générale $\mathcal{N}(\mu,\sigma^2)$ $f(x)=\dfrac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\dfrac{1}{2}\!\left(\dfrac{x-\mu}{\sigma}\right)^{\!2}\right)$.
$\mathbb{E}(X)=\mu$（espérance），$\sigma$（écart-type），$\mathrm{Var}(X)=\sigma^2$.
$X\sim\mathcal{N}(0,1)\Rightarrow \sigma X+\mu\sim\mathcal{N}(\mu,\sigma^2)$.
Note — 计算 $\mathcal{N}(0,1)$ 矩 定义 $\varphi(t)=\mathbb{E}(e^{tX})=e^{t^2/2}$（解 $\varphi'=t\varphi,\varphi(0)=1$）。展开 $e^{t^2/2}=\sum t^{2k}/(k!2^k)$ 与 $\sum \mathbb{E}(X^k)t^k/k!$ 系数对比 → 矩公式。
Exercices 3.3.1-3 通过 transfert 直接算 $\mathbb{E}(X^k),\mathrm{Var}(X)$（uniforme / exp / normale）→ 上面公式。

3.4 Indépendance

Déf 3.4.1$X_1 \perp\!\!\!\perp X_2$（2 个 VA） $\forall(A,B)\in\mathcal{B}(\mathbb{R})^2$： $$\mathbb{P}(X_1\in A, X_2\in B)=\mathbb{P}(X_1\in A)\cdot \mathbb{P}(X_2\in B).$$
Déf 3.4.2Indépendance mutuelle ($n$ VA) $\forall (A_1,\dots,A_n)\in\mathcal{B}(\mathbb{R})^n$： $$\mathbb{P}(X_1\in A_1,\dots,X_n\in A_n)=\prod_{i=1}^n \mathbb{P}(X_i\in A_i).$$ 注意：两两独立 ≠ 互相独立（pairwise vs mutually）。
Prop 3.4.1 — 关键3 种等价刻画（2 个 VA） 以下等价：
  1. $X_1$ 与 $X_2$ 独立
  2. $\mathbb{P}_{(X_1,X_2)}=\mathbb{P}_{X_1}\otimes \mathbb{P}_{X_2}$（联合 = 边际乘积）
  3. $\forall \varphi,\psi\in C_c(\mathbb{R}),\ \mathbb{E}(\varphi(X_1)\psi(X_2))=\mathbb{E}(\varphi(X_1))\,\mathbb{E}(\psi(X_2))$
证：(1)⇒(2) 由 classes monotones；(2)⇒(3) 由 Fubini；(3)⇒(1) 由逼近 + monotones。
Prop 3.4.2$n$ 个 VA 的等价刻画 类似：$\mathbb{P}_{(X_1,\dots,X_n)}=\bigotimes_{i=1}^n \mathbb{P}_{X_i}$；或 $\mathbb{E}\!\left(\prod \varphi_i(X_i)\right)=\prod \mathbb{E}(\varphi_i(X_i))$.
Note — 重要推论 若 $X_1,X_2$ 独立且都可积：$\mathbb{E}(X_1 X_2)=\mathbb{E}(X_1)\mathbb{E}(X_2)$；故 $\mathrm{Var}(X_1+X_2)=\mathrm{Var}(X_1)+\mathrm{Var}(X_2)$。
反向不成立：$\mathbb{E}(XY)=\mathbb{E}(X)\mathbb{E}(Y)$（即 $\mathrm{Cov}=0$）不蕴含独立。
Note — 联合密度判独立 若 $(X_1,X_2)$ 有联合密度 $f_{(X_1,X_2)}$ 且能写为 $f_{(X_1,X_2)}(x,y)=g(x)h(y)$ 几乎处处，则 $X_1\perp\!\!\!\perp X_2$，$X_1$ 密度 $\propto g$，$X_2$ 密度 $\propto h$。
Exercice 3.4.1 — 模拟 Poisson $(X_i)$ i.i.d. $\mathcal{U}([0,1])$，$Y_i=\prod_{j\le i}X_j$。固定 $\lambda>0$，$u_\lambda=e^{-\lambda}$： $\mathbb{P}(Y_i>u_\lambda \ge Y_{i+1})=\dfrac{u_\lambda \lambda^i}{i!}$ → 算法：循环乘 $X_j$ 直到首次 $\le e^{-\lambda}$，返回 $i-1$ 模拟 $\mathcal{P}(\lambda)$.
Exercice 3.4.2 若 $\mathbb{E}(\varphi(X,Y))=\!\!\int\varphi(x,y)\lambda e^{-\lambda x}\mu e^{-\mu y}dxdy$（密度可分离），则：
  • $X\sim\mathcal{E}(\lambda),\ Y\sim\mathcal{E}(\mu)$
  • $X\perp\!\!\!\perp Y$
  • $X+Y$ 密度：$\lambda=\mu$ → $\lambda^2 x e^{-\lambda x}\mathbf{1}_{x>0}$（Erlang/Gamma(2,$\lambda$)）；$\lambda\ne\mu$ → $\lambda\mu \dfrac{e^{-\mu x}-e^{-\lambda x}}{\lambda-\mu}\mathbf{1}_{x>0}$
