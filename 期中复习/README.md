# DS 期中知识复习 · v1.0.0

日期：2026-10-11。在线入口：https://n1cola5f.github.io/theorie-mesure/ds/ 。本地 HTTP 入口：`site/ds/index.html`。独立于全学期阅读器 v1.6.1。

## 内容与依据

从零开始，先识别符号，再按第 1–8 章读完官方考纲的 100 个条目。中文补充对象、条件、例子、反例和理解提示；法语使用教师 Programme 原 PDF 的矢量内容，不重录措辞或公式，原有重点加黑。15 个指定证明各有中文逐步讲解，每一步标注定义、定理、性质或前一步；法语仍是 Preuves 原 PDF。

第 7–8 章只准备知识表述。第 1–6 章承担知识与应用；本次没有要求证明清单以外的证明。TD1–TD4 只提供前两部分的练习建议与官方题解 PDF 入口，不把全套题目搬进正文。不创建刷题、模拟考试、计时或自动评分流程。

已纳入 CM05、官方考纲、官方证明及新上传的 TD2–TD4 官方答案。官方答案包含题目，TD4 无须再上传单独题单。个人答案、错题与往年 DS 不是必需输入。日期为用户确认的 2026-10-20 北京时间，闭卷，禁用计算器；具体时长和开考时刻待确认，90–120 分钟仅为用户估计。

官方考纲第 1 页明确知识范围包括第 1–8 章，不能用“习题与证明截止多重积分”删掉 CM05。概率章节不入 DS，但概率测度定义、第一 Borel–Cantelli、Cantor 测度仍在清单中。去掉的 5 个独立课程表述条目记录在 exam.json；不因此删除教师通知列入的 TD1–TD4 Part 1/2。

## 文件与维护

- `exam.json`：日期与确认状态、来源、范围、章顺序、知识与证明依赖。
- `content/knowledge.tex`：100 个中文理解条目，与官方清单顺序一一对应。
- `content/proofs.tex`：15 个中文逐步证明理解稿。
- `content/guides.tex`：符号、阅读方法、各章导读、易错点。
- `assets/`：界面模板、样式、按章节加载与搜索代码。
- `build.py`：检查对应关系，复用既有 XeLaTeX 字体配置，编译宽/窄正文；裁取官方 PDF 原内容流。
- `publish.py`：正常提交 main、gh-pages，同时保留现有网站及 reader/。
- `构建记录.json`、`必要检查.json`、`发布记录.json`：实际运行证据。

正文与公式在构建时统一 XeLaTeX 编译成独立 SVG，中文宋体、拉丁 Latin Modern、数学 Latin Modern Math；法语保持原 PDF 字体。HTML 不实时编译 LaTeX，不内嵌全书，不预载所有章节、证明或原 PDF。首次搜索才读取搜索索引；语言切换只替换当前页的独立图片。宽屏/窄屏排版预先编译，不按缩放临时排版。

一般维护只改 `.tex` 与 `exam.json`；官方文件更新后更改来源日期、版本与日志，再执行：

```powershell
python 期中复习/build.py --reuse
python 期中复习/check.py
python 期中复习/publish.py --publish
```

本地预览：在仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/site/ds/`。直接双击 file: 页面会受浏览器本地 fetch 限制，可用在线入口。字体和数学都预编译，线上读者不需要安装 LaTeX。

若要更新全学期版，用它自己的维护流程；本次不重编其 117 个条目。已有发布器与远程 deploy.mjs 已加入保留 ds/ 的规则，后续重新部署不会遗漏期中版。

必要验证限于编译日志、数量/依赖/资源链接、代表语言切换和目录跳转、窄屏溢出及实际发布；不做截图或全量视觉核验。中文说明是学习稿而非教师官方答案，法语原文与来源入口用于逐条对照。
