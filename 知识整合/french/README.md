# 法语原文：维护说明

法语正文直接取自上传 PDF 的内容流，保留原字形、措辞、公式及定理编号。PDF 已由原作者排版编译，构建时只截取相应段落并转为 SVG，不翻译、重录或用 OCR 重建正文。原有定理框及粗体关键词加黑、加粗；该强调处理不改变文字和数学内容。

网页提供中文、Français、中法对照三种阅读模式。每个中文条目使用稳定 ID 关联原文，相关原文可由多段组成。主摘录直接显示，补充摘录折叠显示；每段保留 PDF 的实际页序链接。法语提取文本只用于搜索和辅助阅读，不替代可见的 PDF 矢量正文。

## 可编辑输入

- originals.json：条目 ID、来源、原定理编号或幻灯片页码，以及必要的对应说明。
- ../course.json：来源的原路径、准确页数、中文/法语标签和版本。
- ../originals.py：读取原 PDF、建立原文块索引、截取内容流、转换和强调处理。
- 原文构建记录.json：自动生成的来源 SHA-256、每段页码/截取范围及统计，不手工修改。

手册中有编号的原文段落使用 block：

~~~json
"dominated-convergence": {
  "extracts": [{"source": "w4", "block": "5.33"}]
}
~~~

以上只展示格式；维护时以原 PDF 的实际编号为准，不照抄示例编号。幻灯片使用 pages，页码为实际 PDF 页序：

~~~json
"polar-coordinates": {
  "extracts": [{"source": "cm4", "pages": [18, 19, 20], "title": "Coordonnées polaires"}]
}
~~~

可以在 extracts 中依次添加多个来源。中文整理稿的补充推导、反例或明确修正不一定与讲义逐字对应，此时必须添加 note.zh 与 note.fr 说明；法语侧仍保留原文，不把自写的法语说明混作教师正文。来源说明和导航文案属于网页界面，不是讲义原文。

## 更新流程

1. 阅读新资料，把原文件登记到 course.json；保留原始 PDF，不改原内容。
2. 在中文内容中新增或修订条目，同步更新 originals.json。每个启用条目都必须有原文对应；缺少映射会阻止发布。
3. 沿用 ../build.py --reuse。来源哈希或原文范围改变会生成新矢量；未变的中文 XeLaTeX 片段可复用。
4. 原文索引只把真实粗体课程标题作为边界，不能将公式下标、正文中的交叉引用误作章节；习题块不导入。
5. 必要编译与功能检查后更新发布记录，最后生成不可覆盖的版本清单。

build/originals 内的索引、裁切 PDF 和 SVG 都是可再生缓存。更改原文识别逻辑时增加 index_version；更改强调算法时增加矢量缓存键中的 bold 版本，避免复用旧效果。

v1.6.0 默认构建分文件在线站点。法语矢量使用独立 SVG，每个文件带齐所需字形，按当前章节和所选语言请求；补充原文展开时加载。章节 JSON、搜索索引与矢量资源分别保存，PDF 页码链接直接指向 GitHub Pages 的 origin/。这个步骤沿用原文映射、矢量内容和黑色粗体强调；本地 v1.5.0 备份与 v1.5.1 单文件版保留。之后运行 ../publish.py --publish 更新同一在线网址。

本版覆盖网页已有的 117 个条目，不是将全部原 PDF 逐页搬入网页。TD 题目与题解仍不进入知识正文。
